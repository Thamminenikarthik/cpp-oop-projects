
Student Inventory Management System (C++ OOP)

Overview:
The Student Inventory Management System is a Command Line Interface (CLI) application developed using C++ and Object-Oriented Programming concepts. The system manages inventory records such as product ID, name, price, and quantity, and supports selling products and generating sales summaries using file handling for data storage.

Features:
- Add Product
- View All Products
- Delete Product
- Sell Product
- Search Product by ID
- Sales Summary
- Low Stock Alert
- File Handling for Data Storage
- Menu Driven Interface

OOP Concepts Used:
- Classes and Objects
- Encapsulation
- Member Functions
- File Handling
- Vectors
- Modular Programming

Files Used:
- products.txt → Stores inventory data
- sales.txt → Stores sales records

How to Run:
1. Compile: g++ main.cpp -o inventory
2. Run: ./inventory

Conclusion:
This project demonstrates how Object-Oriented Programming and File Handling can be used to build a real-world Inventory Management System in C++ with product management, sales tracking, and persistent storage.
